sits inside the project path, whose name contains "voynich"; a judge told to read files there would learn the source.

(conditions renamed full, centre-l0 … centre-l5), and judges write their answers to `imgstudy_a/answers/`; the answers
are then copied unchanged to `experiments/results/e094_judges/` under the prereg's file names (`<COND>_j<k>.json`).
